# Происхождение демонстрационных материалов

`products.csv` и `products.json` содержат десять вымышленных настольных органайзеров/лотков. Они созданы для учебного брифа CatalogDraft, не описывают реальные товары продавца и не содержат клиентских сведений.

`qwen-response.json` — реальный сохранённый ответ Qwen3.7-Plus, режим Auto, 05.11.2026. В исходном запросе переданы только характеристики ORG-001–ORG-003. Вручную сверены материал, цвет, размеры и количество в упаковке.

После первого ответа формулировка названия ORG-003 «чёрный металл» уточнена отдельным запросом: материал и цвет должны читаться как разные характеристики. Qwen вернул название «Подставка «Ячейка», металл, чёрный цвет». Сравнением подтверждено, что остальные поля не изменились. Полные использованные запросы — в `docs/prompts.md`.

Кнопка загрузки примера применяет этот сохранённый ответ только к учебному каталогу с идентификатором `demo-catalog-v1`. Работа с собственной таблицей требует нового запроса с её идентификатором.

`expected-approved.csv` — независимо подготовленный эталон для проверки C1–C7: одна одобренная карточка ORG-001 с контрольным названием «Органайзер «Линия», серый, 20 × 10 × 8 см». Это ожидаемый результат теста, а не заявленный исходный ответ Qwen. Эталон составлен отдельно от экспортирующей функции приложения.

`demo-data.js` в корне содержит те же товары и финальный ответ, чтобы приложение открывалось с диска без загрузки JSON через сеть.

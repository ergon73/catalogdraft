# Использованные запросы и контекст

Основная реализация выполнена с Codex по согласованному брифу CatalogDraft. Прямое поручение пользователя: «ок, приступай к реализации». Бизнес-правила и сценарии зафиксированы в docs/rules.md до реализации. Codex не выдаётся за Qwen.

Qwen3.7-Plus, режим Auto, 05.11.2026: два фактических запроса ниже. Использованы только вымышленные характеристики трёх товаров. Ответ применялся как черновик и проверялся по исходникам.

## Запрос 1

```text
Подготовь учебные черновики товарных карточек для CatalogDraft. Все товары вымышлены. Используй ТОЛЬКО перечисленные характеристики: не добавляй свойства, обещания, сертификаты, гарантию, цены, страну производства или сценарии, не подтверждённые данными. Коротко и естественно опиши материал, цвет, размеры и количество в упаковке.

Верни ровно один JSON-объект без Markdown и окружающего текста:
{"format":"catalogdraft.response.v1","catalog_id":"demo-catalog-v1","cards":[{"sku":"ORG-001","title":"...","bullets":["...","..."],"description":"..."}, ...]}

Нужны ровно 3 cards для ORG-001, ORG-002, ORG-003. Не добавляй поля. Title: 10–100 символов. Bullets: 1–4 строки по 10–160 символов. Description: 40–600 символов. Размеры: width_cm — ширина, depth_cm — глубина, height_cm — высота. pack_qty — количество товара в упаковке.

Исходные данные:
[
  {
    "sku": "ORG-001",
    "name": "Органайзер «Линия»",
    "material": "Полипропилен",
    "color": "Серый",
    "width_cm": "20",
    "depth_cm": "10",
    "height_cm": "8",
    "pack_qty": "1"
  },
  {
    "sku": "ORG-002",
    "name": "Органайзер «Секция»",
    "material": "Бамбук",
    "color": "Натуральный",
    "width_cm": "24",
    "depth_cm": "12",
    "height_cm": "10",
    "pack_qty": "1"
  },
  {
    "sku": "ORG-003",
    "name": "Подставка «Ячейка»",
    "material": "Металл",
    "color": "Чёрный",
    "width_cm": "18",
    "depth_cm": "9",
    "height_cm": "9",
    "pack_qty": "1"
  }
]
```

## Запрос 2

```text
Уточни только название ORG-003. Формулировка «чёрный металл» может читаться как вид металла, которого нет в исходнике. Нужна однозначная передача двух отдельных фактов: материал — металл, цвет — чёрный. Используй название «Подставка «Ячейка», металл, чёрный цвет». Остальные тексты и поля сохрани без изменений. Верни полный JSON-объект того же формата без Markdown.
```

## Проверка результата

В обоих ответах ровно три карточки. После второго запроса изменилось только название ORG-003; материал, цвет, размеры, количество и остальные тексты сохранены. Контроль структуры и количеств автоматизирован, содержание демотекстов сверено вручную.

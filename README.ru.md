# CatalogDraft — инструкция

[Открыть демо](https://ergon73.github.io/catalogdraft/) · [English](README.md)

Локальная мастерская товарных текстов для продавца или контент-менеджера небольшого каталога. Исходные характеристики, черновик и ручное одобрение находятся в одном процессе. Это учебный проект; все товары демо вымышлены.

## Быстрый проход

1. Откройте демо либо распакуйте архив и откройте `index.html` обычным браузером.
2. Нажмите «Попробовать демо»: появятся 10 товаров с полными характеристиками.
3. Нажмите «Загрузить пример ответа»: три карточки получат черновики. Это сохранённый реальный ответ Qwen, а не новая генерация.
4. Откройте «Проверить» у ORG-001. Сверьте материал, цвет, размеры и комплектацию с исходными полями.
5. При необходимости отредактируйте текст. Отметьте ручную сверку и нажмите «Одобрить».
6. Перейдите в «Передача» и скачайте CSV одобренных карточек. Поиск и фильтр каталога не ограничивают эту выгрузку.
7. Скачайте резерв JSON перед переносом работы. На другом браузере или адресе выберите «Восстановить резерв» и подтвердите замену после проверки файла.
8. После обновления сохраняются тексты и одобрения. Незасохранённую правку редактора перед закрытием браузера следует сохранить как черновик.

## Своя таблица и Qwen

Подготовьте CSV по [примеру](demo/products.csv): UTF-8, разделитель `;`, до 20 товаров и 100 КБ. Размеры — в сантиметрах. Неполные характеристики отмечаются отдельно; для их изменения исправьте исходный файл и явно замените каталог. Идентичная повторная загрузка сохраняет работу.

Выберите до трёх товаров и нажмите «Собрать запрос». Перенесите полный запрос в Qwen, затем сохраните содержимое ответа как чистый JSON-файл. Загрузите его кнопкой «Загрузить ответ Qwen». Приложение не отправляет данные в нейросеть и не использует API-ключ.

Ответ от другой таблицы, неизвестный артикул, повтор SKU, неверные поля и Markdown вместо JSON отклоняются без изменения текущих данных. Корректный ответ становится черновиком. Формальная проверка структуры не проверяет истинность всех утверждений — это делает человек.

## Сохранение и ограничения

- Данные хранятся в `localStorage` текущего браузера и адреса страницы; общей базы и автоматического переноса нет.
- Резерв сохраняет весь каталог, тексты и одобрения. Восстановление проверяет его целиком и затем заменяет текущую работу с подтверждением.
- При недоступном хранилище остаётся режим работы в памяти с предупреждением. Повреждённое сохранение не заменяется молча демоданными.
- Правка одобренного текста снимает одобрение и требует новой сверки.
- CSV предназначен для передачи текстов, а не для прямой загрузки на конкретную площадку. Формулы в текстовых ячейках нейтрализуются апострофом при экспорте.
- Категория демо — настольные органайзеры. Цены, сертификаты и обещания результата не добавлялись.

Для разработки: `npm ci`, `npm test`, `npm run test:e2e`. Для локального HTTP-просмотра: `npm run serve` и `http://127.0.0.1:8781/`. Node нужен для этих команд, но не для открытия приложения с диска.
